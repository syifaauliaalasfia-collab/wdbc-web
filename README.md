# Prediksi Kanker Payudara (WDBC) - Streamlit

Jalankan lokal:

    pip install -r requirements.txt
    streamlit run app.py

Deploy ke Streamlit Cloud: unggah folder ini ke GitHub, pilih `app.py` sebagai main file.
Model dilatih ulang otomatis saat app pertama dibuka (tanpa pickle), jadi tidak bergantung versi scikit-learn.
